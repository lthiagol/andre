# andre — open work items

Hand-maintained list of open work. Remove an item when it lands; the history of
shipped changes lives in `CHANGELOG.md`. Direction and version status live in
`ROADMAP.md`.

## Release

- [ ] Rotate the `HOMEBREW_TAP_TOKEN` secret — it holds a classic PAT that
      GitHub now rejects with `401 Bad credentials`. It is no longer used: the
      tap checkout and push use the `ANDRE_TAP_SSH_KEY` deploy key, and the
      PR uses `ANDRE_TAP_PR_TOKEN`. The old secret can be deleted, or
      refreshed if some other workflow still reads it.

## CI

- [ ] Decide whether CI needs a macOS runner. Both workflows are
      `ubuntu-latest` only; the docs previously claimed Linux + macOS. The new
      `release-assets` job does use `macos-latest` (to build the macOS
      binaries), but the test gates still run on Linux only.
- [ ] Pin the CI runner images. `ubuntu-latest` is migrating to Ubuntu 26.04
      and `macos-latest` to macOS 26 in November 2026; the workflows use the
      moving `-latest` labels, so an image change can break the gates
      without a repo change.

# andre — open work items

Hand-maintained list of open work. Remove an item when it lands; the history of
shipped changes lives in `CHANGELOG.md`. Direction and version status live in
`ROADMAP.md`.

## Release

- (nothing open) — the dead `HOMEBREW_TAP_TOKEN` secret was deleted from the
    repo's GitHub Actions secrets on 2026-11-02; the tap job uses
    `ANDRE_TAP_SSH_KEY` (checkout/push) and `ANDRE_TAP_PR_TOKEN` (PR only).

## CI

- [ ] Decide whether CI needs a macOS runner. Both workflows are
      `ubuntu-latest` only; the docs previously claimed Linux + macOS. The new
      `release-assets` job does use `macos-latest` (to build the macOS
      binaries), but the test gates still run on Linux only.
- [ ] Pin the CI runner images. `ubuntu-latest` has already migrated to
      Ubuntu 26.04 (the gates are green on it) and `macos-latest` is
      migrating to macOS 26 in November 2026. Pinning explicit labels
      (`ubuntu-26.04`, `macos-26`) would keep an image change from breaking
      the gates without a repo change.

## Documentation

- (nothing open) — `global.engine` and the native-engine default are documented
      in `REFERENCE.md`, `README.md`, and `andre.yml.example`; the product
      framing now leads with the A.N.D.R.E. backronym (deferred from review
      cycle 1, F-02 — resolved).

# andre — open work items

Hand-maintained list of open work. Remove an item when it lands; the history of
shipped changes lives in `CHANGELOG.md`. Direction and version status live in
`ROADMAP.md`.

## Release

- (nothing open) — the dead `HOMEBREW_TAP_TOKEN` secret was deleted from the
    repo's GitHub Actions secrets on 2026-11-02; the tap job uses
    `ANDRE_TAP_SSH_KEY` (checkout/push) and `ANDRE_TAP_PR_TOKEN` (PR only).

## CI

- (nothing open) — runner images are pinned to `ubuntu-24.04` (what
      `ubuntu-latest` currently maps to) for stability; `ubuntu-26.04`
      exists as a label and can be adopted deliberately. The test gates are
      Linux-only by decision (2026-11-02): the TUI is exercised locally on
      macOS during development, so a macOS CI gate was judged not worth the
      runner minutes.

## Documentation

- (nothing open) — `global.engine` and the native-engine default are documented
      in `REFERENCE.md`, `README.md`, and `andre.yml.example`; the product
      framing now leads with the A.N.D.R.E. backronym (deferred from review
      cycle 1, F-02 — resolved).

## Ideas (not yet planned)

- More themes.
- Richer config validation.
- Adoption-UX expansions.
- Whether to expand scope beyond Stow post-1.0 (undecided).

## Release state (as of v1.0.0-rc1, 2026-10-30)

- `v1.0.0-rc1` published as a GitHub **pre-release** (its four binaries are
  historical — binary releases were dropped on 2026-11-02; the supported
  install methods are now Homebrew and from source).
- `wip` is ahead of `stable`; `stable` is fast-forwarded from `wip` once CI
  is green (see AGENTS.md branching model).
- The Homebrew tap (`lthiagol/homebrew-tap`) has both `Formula/andre.rb` and
  `Formula/andre-dev.rb` bumped to `v1.0.0-rc1` (formulas build from source).
- A tag push runs: CI gates → GitHub Release (notes only, no assets) →
  Homebrew tap PR.
